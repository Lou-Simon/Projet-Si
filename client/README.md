# Client (Vue 3 + Vite)

Base propre pour commencer ton architecture (navbar, layouts, pages, etc.).

## Lancer le projet

- `npm install`
- `npm run dev`

## Structure préparée

- `src/assets/styles`
- `src/components/navbar`
- `src/components/shared`
- `src/layouts/public`
- `src/layouts/private`
- `src/pages/public`
- `src/pages/private`
- `src/pages/errors`
- `src/router/guards`
- `src/router/routes`
- `src/composables`
- `src/services`
- `src/stores`
- `src/utils`
